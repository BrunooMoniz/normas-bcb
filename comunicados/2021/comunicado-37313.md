# Comunicado N° 37.313

Comunicamos que os acessos às aplicações *web* e *webservices* do domínio BCB.GOV.BR, nos ambientes de homologação e produção, passarão a utilizar o protocolo TLS v1.2 ou superior a partir das datas abaixo:

|  |  |
| --- | --- |
| Ambiente | Data |
| Homologação | 19.7.2021 |
| Produção | 16.8.2021 |

Eventuais dúvidas podem ser endereçados à central de atendimento, por meio do telefone (61)3414-2156 ou pelo endereço eletrônico suporte.ti@bcb.gov.br.

                Eduardo Weller

                Chefe de Unidade, em exercício
