# Comunicado Nº 22.596

Com base no que determina o MCR 3-5-11-“a”, comunicamos a criação de códigos específicos no sistema Registro Comum de Operações Rurais (Recor), para registro dos financiamentos referentes aos seguintes empreendimentos:

|  |  |  |
| --- | --- | --- |
| Codigo | Descrição do Empreendimento | Finalidade/Atividade/Modalidade |
| 92423152 | Composição ou Renegociação de dívidas rurais formalizadas com base na resolução 4.028, de 18.11.2011, com predominância da finalidade custeio agrícola. | Custeio Agrícola-Renegociação |
| 92423262 | Composição ou Renegociação de dividas rurais formalizadas com base na resolução 4.028, de 18.11.2011, com predominância da finalidade investimento agrícola. | Investimento Agrícola-Renegociação |
| 92423444 | Composição ou Renegociação de dívidas rurais formalizadas com base na resolução 4.028, de 18.11.2011, com predominância da finalidade custeio pecuário | Custeio Pecuário-Renogociação |
| 92423664 | Composição ou Renegociação de dívidas rurais formalizadas com base na resolução 4.028, de 18.11.2011, com predominância da finalidade investimento pecuário. | Investimento Pecuário-Renegociação |

2.         A consulta aos citados códigos pode ser efetuada mediante a utilização da transação PCOR910-Consulta às tabelas RECOR, opção TCOR003, disponível no Sistema de Informações Banco Central (SISBACEN).

3.         Este Comunicado entra em vigor na data de sua publicação.
