# Comunicado Nº 22.552

Comunico que, com base no disposto no art. 15 da Circular nº 3.567, de 12 de dezembro de 2011, os limites máximos para solicitação de arquivos contendo os dados de clientes - para efeito de geração do documento de código 3046 (Posição de Clientes no SCR) -, relativamente ao Sistema de Informações de Créditos (SCR), devem ser os seguintes:

 I - 3 (três) solicitações por mês, para requisições via **web**;

 II - 10 (dez) solicitações por mês, com no máximo 1.000.000 (um milhão) de clientes cada, para requisições realizadas por meio do documento de código 3045.

2. Os referidos limites não se aplicam para consultas às informações de clientes realizadas por meio de página **web** ou por meio do **web service**.

3. Torno sem efeito o Comunicado nº 21.331, de 3 de agosto de 2011.
