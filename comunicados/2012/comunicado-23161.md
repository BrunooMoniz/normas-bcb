# Comunicado Nº 23.161

Comunicamos as novas datas do STA, conforme apresentadas na quarta reunião do sistema realizada em 13/11/2012, no Banco Central em Brasília.

2. O STA será disponibilizado em Produção em 25/3/2013. A partir dessa data, as instituições podem utilizar o novo sistema ou continuar utilizando o PSTA. Lembramos que as instituições podem fazer a migração para o STA de forma total ou parcial (arquivo por arquivo). Favor consultar o Manual do sistema para mais detalhes.

3. O PSTAW10 e o PSTAC10 serão desativados em 24/6/2013.

4. Maiores esclarecimentos podem ser obtidos com o Banco Central, na página do STA, [http://www.bcb.gov.br/?TRANSFARQ](http://www.bcb.gov.br/?TRANSFARQ "Ir para o sítio http://www.bcb.gov.br/?TRANSFARQ."), ou pelo email [sta@bcb.gov.br](mailto:sta@bcb.gov.br "Ir para o sítio sta@bcb.gov.br.").
