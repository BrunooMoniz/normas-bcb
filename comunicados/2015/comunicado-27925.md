# Comunicado Nº 27.925

O certificado digital do Banco Central do Brasil utilizado nos sistemas disponíveis na Internet será substituído no dia 7 de junho de 2015. O novo certificado digital, bem como sua cadeia de confiança, está disponível em [https://www.bcb.gov.br/?certdig](https://www.bcb.gov.br/?certdig "Ir para o sítio https://www.bcb.gov.br/?certdig.").

Os usuários de serviços *webservices* devem verificar e providenciar os necessários ajustes decorrentes da troca do certificado digital.

Os principais sistemas afetados serão:

|  |  |
| --- | --- |
| Sistema | Endereço |
| BCCorreio | https://bccorreio.bcb.gov.br/bccorreiows/ |
| PTAX | https://ptax.bcb.gov.br/wsmoeda/ |
| RDR | https://www3.bcb.gov.br/rdrws/ |
| SCR | https://www3.bcb.gov.br/wsscr2/ |
| SGS | https://www3.bcb.gov.br/wssgs/services/FachadaWSSGS/ |
| STA | https://sta.bcb.gov.br/staws/ |
