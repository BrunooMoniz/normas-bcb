# Comunicado Nº 27.461

Comunicamos que o documento que descreve o layout dos arquivos de remessa de dados pelo sistema Bacen Jud 2.0 relativos a todas as ordens judiciais por ele transmitidas, exceto as de requisição de informações, está disponível para as instituições participantes do sistema na página do Banco Central do Brasil na internet, no endereço http://www.bcb.gov.br/?BCJ2ARQSIF.

2.      As instituições participantes do sistema Bacen Jud 2.0 deverão adequar seus sistemas internos ao novo layout dos arquivos de remessa de dados pelo Bacen Jud 2.0 até 7 de dezembro de 2015.

3.      Eventuais dúvidas sobre o sistema Bacen  Jud  2.0  deverão ser dirimidas exclusivamente pelo e-mail [bacenjud2@bcb.gov.br](mailto:bacenjud2@bcb.gov.br "Ir para o sítio bacenjud2@bcb.gov.br.").

                                       Brasília, 17 de março de 2015.
