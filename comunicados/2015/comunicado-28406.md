# Comunicado N° 28.406

Comunicamos que a partir de 13 de setembro de 2015 o endereço IP de acesso a  Web Services do Sistema de Transferência de Arquivos (STA) passará a ser 200.218.209.119, entretanto, destacamos que o seu endereço [https://sta.bcb.gov.br/staws](https://sta.bcb.gov.br/staws "Ir para o sítio https://sta.bcb.gov.br/staws.") não será alterado.

Maiores esclarecimentos podem ser obtidos com o Banco Central, na página do STA, [http://www.bcb.gov.br/?TRANSFARQ](http://www.bcb.gov.br/?TRANSFARQ "Ir para o sítio http://www.bcb.gov.br/?TRANSFARQ."), ou pelo email [sta@bcb.gov.br](mailto:sta@bcb.gov.br "Ir para o sítio sta@bcb.gov.br.").
