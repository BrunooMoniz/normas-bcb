# Comunicado N° 29.096

Comunicamos o estabelecimento do cronograma para testes, homologação e entrada efetiva em produção das cooperativas singulares de crédito no Sistema Bacen Jud 2.0.

2.         A entrada efetiva em produção dessas instituições no Bacen Jud 2.0 se dará após uma fase de testes individuais, sem troca de arquivos com o Bacen, e uma fase de homologação, com troca de arquivos com o Bacen.

3.         Os testes individuais descritos em “Roteiro mínimo de testes para entrada de novas instituições”, sem troca de arquivos com o Bacen, deverão ser executados com sucesso até 01.04.2016.

 4.         Os testes de homologação descritos em “Roteiro de Homologação com o Banco Central para as Instituições Participantes – 04/2016”, que envolvem troca de arquivos com o Bacen no ambiente de homologação, deverão ser executados entre 04.04.2016 e 29.04.2016.

 5.         Os roteiros dos testes acima mencionados estão disponíveis na página do Banco Central na internet, no endereço: [http://www.bcb.gov.br/?BCJ2TESTES](http://www.bcb.gov.br/?BCJ2TESTES "Ir para o sítio http://www.bcb.gov.br/?BCJ2TESTES.").

 6.         A partir de 02.05.2016, inclusive, as cooperativas singulares de crédito deverão receber e responder os arquivos de ordens judiciais no ambiente de produção do Sistema Bacen Jud 2.0.

 7.         Eventuais dúvidas sobre o Sistema Bacen Jud 2.0 deverão ser dirimidas exclusivamente pelo e-mail bacenjud2@bcb.gov.br.

Brasília, 11 de fevereiro de 2016.
