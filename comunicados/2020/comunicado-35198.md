# Comunicado N° 35.198

O certificado digital SSL *wildcard* do Banco Central do Brasil utilizado em sistemas disponíveis na Internet será substituído no dia 1º de março de 2020. O novo certificado digital, bem como sua cadeia de confiança, está disponível em https://www.bcb.gov.br/estabilidadefinanceira/certificacaodigital.

Os usuários de serviços *webservices* devem verificar e providenciar os necessários ajustes decorrentes da troca do certificado digital.

Os principais sistemas afetados serão:

|  |  |
| --- | --- |
| Sistema | Endereço |
| BCCorreio | https://bccorreio.bcb.gov.br/bccorreiows/ |
| PTAX | https://ptax.bcb.gov.br/wsmoeda/ |
| RDR | https://www3.bcb.gov.br/rdrws/ |
| SCR | https://www3.bcb.gov.br/wsscr2/ |
| SGS | https://www3.bcb.gov.br/wssgs/services/FachadaWSSGS/ |
| STA | https://sta.bcb.gov.br/staws/ |
| Dados abertos | https://dadosabertos.bcb.gov.br/ |

Esta substituição não afetará as aplicações acessadas através dos seguintes endereços, para os quais é usado certificado SSL de validação estendida:

https://www.bcb.gov.br

https://www3.bcb.gov.br

https://www7.bcb.gov.br
