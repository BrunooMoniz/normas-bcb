# COMUNICADO N. 009674

```
                        COMUNICADO N. 009674
                        --------------------

                             Divulga os procedimentos a serem utili -
                             zados na remessa de informações no âmbi-
                             to do sistema Central de Risco de Crédi-
                             to - SCR.

            Comunicamos que a  remessa do  Documento  3030  -   Dados
Agregados  de   Risco  de  Crédito  e  do Documento   3020   -  Dados
Individualizados de Risco de Crédito, de que trata a Circular  3.098,
de  20  de março de 2002, pode ser realizada utilizando-se o software
PSTAW10, disponível no site do Banco Central do Brasil para download,
ou o software Connect Direct.

2.    Utilizando-se  o software PSTAW10 para envio dos  documentos  a
seguir listados, os seguintes códigos devem ser utilizados:

     I  - documento 3020:
     a)código PSTA: R320 - "CENTRAL DE RISCO - DOCUMENTO 3020", e
     b)código Sisbacen: ASCR320.

    II  - documento 3030:
     a)código PSTA: R330 - "CENTRAL DE RISCO - DOCUMENTO 3030", e
     b)código Sisbacen: ASCR330.

3.    No  caso de transmissão através do software Connect  Direct,  a
instituição  deve  entrar  em contato com  a  mesa  do  Sisbacen   no
telefone (61) 414-2156 para maiores esclarecimentos.

4.   Para a troca de informações referentes ao resultado da aplicação
de  críticas  de  qualidade aos documentos citados no  item  1,  será
utilizado o aplicativo PSTAW10 com os seguintes códigos:

     a)para  recebimento pela instituição de relatório  de  erros,  o
        código  R001  -  "CENTRAL DE RISCO - INDÍCIOS DE  ERRO",  com
        código Sisbacen ASCR001; e,
     b)para  recebimento  ou  envio de outros arquivos  não  tratados
        anteriormente,  o código R002 - "CENTRAL DE  RISCO  -  OUTROS
        ARQUIVOS", com código Sisbacen ASCR002.

5.         Os  códigos para a transmissão e recebimento de documentos
do   sistema   Central   de   Risco  de  Crédito   -   SCR    estarão
disponíveis  a  partir  de 28 de junho de 2002.

                    Brasília, 27 de junho de 2002.

Departamento de Supervisão Indireta       Departamento de Informática

Vânio Cesar Pickler Aguiar                José Antônio Eirado Neto
Chefe                                     Chefe
```
