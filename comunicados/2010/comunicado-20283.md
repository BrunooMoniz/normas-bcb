# COMUNICADO N. 020283

```
                        COMUNICADO N. 020283
                        --------------------
                                   Divulga    novo    código     de
                                   empreendimento para registro  de
                                   operações  de crédito  rural  no
                                   Recor.

                        Com base no que determina o MCR 3-5-11-"a",
comunicamos  a criação de código específico a ser utilizado  quando
do  registro  dos  financiamentos rurais  contratados,  no  sistema
Registro   Comum   de  Operações  Rurais  (Recor),   referente   ao
empreendimento abaixo:

CÓDIGO   EMPREENDIMENTO               FINALIDADE/ATIVIDADE/MODALIDADE
11295110 Pimenta-do-Reino (Zoneamento Custeio Agrícola - Lavoura
         Agrícola)

2.                      A   consulta  ao   citado  código  pode  ser
efetuada   mediante a utilização da  transação  PCOR910-Consulta  às
tabelas  RECOR, opção TCOR003, disponível no Sistema  de Informações
Banco Central (SISBACEN).

                                 Brasília, 4  de Novembro  de 2010.

          Gerência-Executiva de Regulação e  Controle das
               Operações Rurais e do Proagro (Gerop)

                    Deoclécio Pereira de Souza
                         Gerente-Executivo
```
