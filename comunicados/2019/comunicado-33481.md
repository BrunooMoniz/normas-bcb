# Comunicado N° 33.481

Comunicamos às instituições participantes do sistema  Bacen Jud 2.0 que serão realizados, no período de 29/4 a 31/5/2019, os testes de homologação da versão 1.10 do documento que descreve o layout dos arquivos trocados com as instituições participantes, compreendendo a inclusão de novos códigos de resposta e modificação de códigos existentes. A nova versão do documento está disponível na página do Banco Central do Brasil - BCB, no endereço https://www.bcb.gov.br/acessoinformacao/bacenjud.

2.                     Os testes serão realizados no ambiente de homologação do Bacen Jud 2.0, envolvendo os arquivos alterados na nova versão do documento de layout dos arquivos trocados com as instituições participantes. Nessa fase da homologação, deverão participar dos testes todas as instituições participantes do Bacen Jud 2.0.

3.                     Durante os testes, o BCB irá gerar ordens ordens fictícias de **bloqueio**, **desbloqueio** e **transferência**, realtivas aos réus listados na tabela do parágrafo a seguir. As instituições participantes deverão responder as ordens recebidas, incluindo respostas de bloqueios, desbloqueios e transferências utilizando  os novos códigos de respostas. A cada segunda-feira do período de homologação, o BCB limpará a base de dados de homologação do sistema e começará um novo ciclo de testes, que seguirá o seguinte cronograma:

|  |  |
| --- | --- |
| Segunda-feira (noite): | Envio de ordens originais de bloqueio. |
| Terça-feira (noite) | Envio de ordens originais de bloqueio. |
| Quarta-feira (madrugada): | Validação semântica das respostas do movimento de segunda-feira. |
| Quarta-feira (noite) | Envio de ordens originais de bloqueio e ordens de reiteração/cancelamento, desbloqueio e transferência. |
| Quinta-feira (madrugada) | Validação semântica das respostas do movimento de terça-feira. |
| Quinta-feira (noite) | Envio de ordens originais de bloqueio e ordens de reiteração/cancelamento, desbloqueio e transferência. |
| Sexta-feira (madrugada) | Validação semântica das respostas do movimento de quarta-feira. |
| Sexta-feira (noite) | Envio de ordens originais de bloqueio e ordens de reiteração/cancelamento, desbloqueio e transferência. |
| Segunda-feira (madrugada) | Validação semântica das respostas do movimento de quinta-feira. |
| Segunda-feira (dia) | Geração de relatórios e limpeza da base de dados para início de um novo ciclo de testes. |
