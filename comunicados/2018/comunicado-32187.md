# Comunicado N° 32.187

|  |  |  |  |
| --- | --- | --- | --- |
| |  | | --- | |  | |  | | Em conformidade com o disposto na Circular nº 3.629, de 19 de fevereiro de 2013, comunico a seguinte atualização no volume 3 da versão 4.11 do Catálogo de Serviços do SFN, publicado em 23/3/2018:     2. Alteração das mensagens COR0001 - Requisição de inclusão ou alteração de Cédula de Crédito Rural e COR0005 - Requisição de alteração de campos complementares de Cédula de Crédito Rural.     3. Os arquivos atualizados dos volumes 3 e 4 do Catálogo, da Planilha de Alterações, dos XSD dos eventos COR0001 e COR0005 e do DRN que originou esta atualização estão disponíveis no sítio internet da Comunicação Eletrônica de Dados do Banco Central do Brasil (http://www.bcb.gov.br/?CEDSFNSERVICOS).    4. Dúvidas a respeito do Grupo de Serviços COR deverão ser encaminhadas por meio do endereço eletrônico sicor.derop@bcb.gov.br.           Eduardo Weller  Comitê Gestor da Comunicação Eletrônica de Dados no Âmbito do SFN | |
