# Comunicado N° 31.712

Comunicamos que o Sistema de Correio Eletrônico do Banco Central do Brasil (BC Correio) está disponível para acesso pelos endereços:

a. por meio de browser: [https://bccorreio.bcb.gov.br/bccorreio](https://bccorreio.bcb.gov.br/bccorreio "Ir para o sítio https://bccorreio.bcb.gov.br/bccorreio.")

b. web service: [https://bccorreio.bcb.gov.br/bccorreiows](https://bccorreio.bcb.gov.br/bccorreiows "Ir para o sítio https://bccorreio.bcb.gov.br/bccorreiows.")

Os endereços de acesso ao BC Correio de Homologação (Ambiente de Teste) permanecem os mesmos:

a. por meio de browser: [https://www9.bcb.gov.br/bccorreio](https://www9.bcb.gov.br/bccorreio "Ir para o sítio https://www9.bcb.gov.br/bccorreio.")

b. web service: [https://www9.bcb.gov.br/bccorreiows](https://www9.bcb.gov.br/bccorreiows "Ir para o sítio https://www9.bcb.gov.br/bccorreiows.")

A partir de 31.3.2018, os endereços anteriores de acesso ao BC Correio serão desativados. Dessa forma, recomenda-se a atualização imediata para os novos endereços do BC Correio em seus processos automatizados.

 Dúvidas podem ser esclarecidas junto à Mesa de Auxílio do Banco Central, no telefone (61) 3414-2124.
