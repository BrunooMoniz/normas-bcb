# Comunicado Nº 23.377

Com base no que determina o art. 3º da circular nº 3.620, de 21.12.2012 e no MCR 3-5-A-5-“a”, comunicamos a criação de código específico de fonte de recursos e de código de programa para registro no Sistema de Operações de Crédito Rural e do Proagro (Sicor):

I – código de fonte de recursos:

|  |  |
| --- | --- |
| CÓDIGO | DESCRIÇÃO |
| 0260 | COMPULSÓRIO SOBRE RECURSOS À VISTA – REFORÇO DO INVESTIMENTO (CIRC 3.622) |

II – código de programa:

|  |  |
| --- | --- |
| CÓDIGO | DESCRIÇÃO |
| 0160 | PRI - PROGRAMA DE REFORÇO DO INVESTIMENTO (CIRC 3.622) |

2. A consulta aos referidos códigos está disponivel no endereço eletrônico: [www.bcb.gov.br](http://www.bcb.gov.br "Ir para o sítio www.bcb.gov.br.") > Sistema Financeiro Nacional > Crédito Rural > Tabelas.

3.  Este Comunicado entra em vigor na data de sua publicação.
