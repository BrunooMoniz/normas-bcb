# Comunicado Nº 24.502

|  |
| --- |
|  |
|  |
| Em conformidade com o disposto na Circular nº 3.629, de 19 de fevereiro de 2013, comunico a publicação da versão 7.5 do Manual de Redes do SFN e do Dicionário de Domínios associado ao Catálogo de Serviços do SFN, no sítio do Banco Central do Brasil, na Internet, em Sistema Financeiro Nacional, Comunicação Eletrônica de Dados ([http://www.bcb.gov.br/?CEDSFN](http://www.bcb.gov.br/?CEDSFN "Ir para o sítio http://www.bcb.gov.br/?CEDSFN.")).    2. Com relação às alterações no Dicionário de Domínios, deverão ser observadas as respectivas datas de ativação e de desativação para os ambientes de homologação e de produção.      Eduardo Weller  Comitê Gestor da Comunicação Eletrônica de Dados no Âmbito do SFN |
