# Comunicado Nº 24.184

Comunicamos que se encontra disponível, na página do Banco Central do Brasil na Internet, no endereço eletrônico http://www.bcb.gov.br/?ACAM202, o leiaute do arquivo ACAM202, destinado à transferência de dados registrados no antigo Sistema Câmbio para as instituições autorizadas a operar no mercado de câmbio.

 2. O arquivo ACAM202:

 I - estará disponível para recepção pelas instituições, a partir de 5 de agosto de 2013, por meio do Sistema de Transferência de Arquivos (STA);

 II - conterá somente os contratos e eventos de câmbio registrados no antigo Sistema Câmbio (Plataforma Alta - Mainframe).

 3. O Banco Central do Brasil desativará em definitivo as transações de consulta do antigo Sistema Câmbio em 31 de janeiro de 2014.

4. Eventuais dúvidas relacionadas ao leiaute poderão ser encaminhadas para o endereço eletrônico cambio.gence@bcb.gov.br.
