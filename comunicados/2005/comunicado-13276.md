# COMUNICADO N. 013276

```
                        COMUNICADO N. 013276
                        --------------------

                                 Comunica os  limites  para  consulta
                                 às informações de cliente no  âmbito
                                 do Sistema de Informações de Crédito
                                 do Banco Central - SCR.

        Comunicamos que, a partir de 1º de maio de 2005,  os  limites
máximos  para solicitação de arquivos contendo os dados  de  clientes
(para efeito de geração do arquivo 3082), relativamente ao Sistema de
Informações de Crédito do Banco Central (SCR) serão os seguintes:

        I  -  3  (três)  solicitações por mês, para  requisições  via
              "web";

        II  - 30 (trinta) solicitações por mês, com no máximo  50.000
              (cinqüenta mil)  clientes  cada,  para  requisição  via
              documento 3081.

2.      Referidos  limites  não  se  aplicam  para  as  consultas  às
informações de clientes por meio de página "web" ou por meio do  "web
service".

                                        Brasília, 27 de abril de 2005
```
