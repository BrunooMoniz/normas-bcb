# COMUNICADO N. 013816

```
                        COMUNICADO N. 013816
                        --------------------
                                 Comunica os  limites  para  consulta
                                 às informações de cliente no  âmbito
                                 do Sistema de Informações de Crédito
                                 do Banco Central - SCR.

        Comunicamos  que,  a  partir de 1º de novembro  de  2005,  os
limites  máximos para solicitação de arquivos contendo  os  dados  de
clientes  (para efeito de geração do arquivo 3082), relativamente  ao
Sistema  de  Informações de Crédito do Banco Central (SCR)  serão  os
seguintes:

        I  -  3  (três)  solicitações por mês, para  requisições  via
"web";

        II  - 80 (oitenta) solicitações por mês, com no máximo 50.000
(cinqüenta mil) clientes cada, para requisição via documento 3081.

2.      Referidos  limites  não  se  aplicam  para  as  consultas  às
informações de clientes por meio de página "web" ou por meio do  "web
service".

                                      Brasília, 27 de outubro de 2005

Departamento de Supervisão Indireta e Gestão da Informação

Cornélio Farias Pimentel
Chefe

Departamento de Tecnologia da Informação

Fernando de Abreu Faria
Chefe
```
