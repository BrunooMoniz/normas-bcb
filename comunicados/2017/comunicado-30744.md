# Comunicado N° 30.744

Comunico que o novo Sistema de Gerência de Autorizações do Sisbacen (Autran) estará disponível a partir de 29 de maio no ambiente de produção ([https://www3.bcb.gov.br/autraninternet](https://www3.bcb.gov.br/autraninternet "Ir para o sítio https://www3.bcb.gov.br/autraninternet.")).

O acesso aos serviços do Sisbacen não será modificado, permanecendo inalterados os atuais código de operador e senha. Entretanto, o novo sistema fará distinção, no cadastro, alteração ou uso de senha, entre caracteres maiúsculos e minúsculos.

A partir das 19 horas do dia 26 de maio de 2017, as transações “PTRAXXX” serão bloqueadas para a realização dos procedimentos de implantação do novo sistema. Fica, assim, temporariamente indisponível qualquer alteração de contas, inclusive a de senha. Os procedimentos não trazem impacto para os demais serviços do Sisbacen.

Recomendo a realização de testes finais do novo sistema, no ambiente de homologação ([https://www9.bcb.gov.br/autraninternet](https://www9.bcb.gov.br/autraninternet "Ir para o sítio https://www9.bcb.gov.br/autraninternet.")), a fim de verificar os impactos em seus processos de trabalho.

Informações sobre o sistema estão disponíveis em [http://www.bcb.gov.br/pt-br/#!/c/GERENNOVOAUT/21](http://www.bcb.gov.br/pt-br/#%21/c/GERENNOVOAUT/21 "Ir para o sítio http://www.bcb.gov.br/pt-br/#!/c/GERENNOVOAUT/21.")

As dúvidas podem ser enviadas para [gerente.sisbacen@bcb.gov.br](mailto:gerente.sisbacen@bcb.gov.br "Ir para o sítio gerente.sisbacen@bcb.gov.br.") ou esclarecidas pelo telefone (61) 3414-2156.
