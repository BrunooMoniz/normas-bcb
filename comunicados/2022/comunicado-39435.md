# Comunicado N° 39.435

O Banco Central do Brasil comunica que, a partir de 1º de fevereiro de 2023, o acesso ao sistema Ptax por usuários credenciados como pessoas físicas será descontinuado, tendo em vista o Comunicado n° 39.153, de 15/09/2022, que informa sobre a descontinuidade
do procedimento de validação de credenciamento de acesso ao Extrato do Registro de Informações no Banco Central do Brasil (Sistema Registrato).

2. Até o dia 31 de janeiro de 2023, as informações de taxas de câmbio no sistema Ptax continuarão disponíveis para usuários credenciados como pessoas físicas.

3. A partir das 19h do dia 21 de novembro de 2022, o sistema Ptax passará a exibir uma mensagem contendo as informações descritas nos parágrafos anteriores, bem como as alternativas de acesso aos dados sobre taxas de câmbio, publicadas no sítio do Banco
Central do Brasil na internet.

4. As informações divulgadas pelo sistema Ptax são também publicadas na página do Banco Central do Brasil na internet, no endereço https://www.bcb.gov.br/estabilidadefinanceira/cotacoesmoedas, que apresenta seis opções de consulta a taxas de câmbio. A equivalência
das opções do menu de consulta do sistema em relação ao sítio na internet é a seguinte:

|  |  |  |
| --- | --- | --- |
| **Opção no Sistema Ptax** | **Opção na página do Banco Central do Brasil** | **Observação** |
| Boletim de câmbio | Consulta de cotações e boletins | - |
| Boletim de câmbio por período | Consulta de cotações e boletins | Disponível apenas para o boletim de fechamento Ptax. |
| Cotações de balanço | Diretamente no endereço:  https://www4.bcb.gov.br/Download/fechamento/aaaammdd.csv | A expressão “aaaammdd” deve ser substituída pelos dígitos do ano, mês e último dia útil do mês para o qual se desejam as cotações. |
| Cotações de contabilidade | Cotações de todas as moedas | Para consulta de datas anteriores ao disponível na tela, utilizar o mesmo método de consulta da opção “Cotações de balanço” acima. |
| Cotações de moedas | Consulta de cotações e boletins | - |
| Cotações mínimas e máximas | Indisponível | - |
| Conversão de moedas | Conversor de moedas | - |
| Dólar americano | Fechamento diário do dólar | - |
| Moeda | Relação de moedas estrangeiras e padrões monetários brasileiros | Equivalência parcial |
| Status dos boletins de câmbio e cotações de contabilidade | Indisponível | - |
