# Comunicado Nº 25.837

|  |
| --- |
|  |
|  |
| O sistema de Extrato do Registro de Informações no Banco Central do Brasil (Sistema Registrato) está disponível para testes em ambiente de homologação.    2. Para acessar o Registrato em ambiente de homologação é necessário utilizar os seguintes endereços eletrônicos:  a) Obtenção da frase de segurança:  https://www9.bcb.gov.br/registrato/publico/obterFraseSeguranca  b) Autocredenciamento, necessita da frase de segurança validada:  https://www9.bcb.gov.br/registrato/publico/autoCredenciamento  c) Acesso ao Registrato (usuário já criado):  https://www9.bcb.gov.br/registrato/dologin  3. O roteiro de testes abaixo é o conjunto mínimo de cenários a serem verificados pelas instituições financeiras.   |  |  |  | | --- | --- | --- | | **Cenário** | **Pré-requisito** | **Resposta esperada** | | 1. Obtenção de frase de segurança | Não há | Frase de segurança criada | | 2. Validar Frase de Segurança com dados corretos | Frase de segurança obtida | Frase de segurança validada (retorno mensageria: IndrValidcFraseSegrc=S) | | 3. Validar Frase de segurança com dados inválidos: frase de segurança não cadastrada ou vencida, cpf não cadastrado. | Não há | Frase de segurança não validada (retorno mensageria: IndrValidcFraseSegrc=N) | | 4. Validar Frase de segurança já validada anteriormente. | Frase de segurança válida | Frase de segurança validada (retorno mensageria IndrValidcFraseSegrc=S). | | 5. Autocredenciamento | Frase de segurança válida | Usuário credenciado | | 6. Login na aplicação | Usuário credenciado | Acesso concedido |   4. Haverá seminário para divulgação do sistema e para esclarecimento de dúvidas no dia 22 de maio de 2014, nas instalações do Banco Central em São Paulo-SP, localizado na Av. Paulista, 1804.  4.1. Cada instituição pode indicar até dois representantes, identificando-os com nome completo, RG (número e órgão emissor com Estado) e nome da instituição.  4.2. As indicações devem ser feitas até o dia 20/5/2014 por meio do email registrato.deati@bcb.gov.br, devendo-se observar estritamente a data para evitar contratempos.  4.3. O seminário será realizado das 13h até às 15h, podendo haver outro, caso o número de inscritos requeira, das 15h30 às 17h30. Os assuntos abordados serão os mesmos, portanto, aqueles que participarem da primeira sessão não poderão participar da segunda.  5. O sistema Registrato entrará em produção, com o acesso no endereço http://www.bcb.gov.br/?REGISTRATO. A mencionada página conterá as informações relacionadas ao Registrato: instruções de uso, descrição do sistema e dos cadastros a ele vinculados (SCR e CCS), links para a obtenção da frase de segurança e o autocredenciamento, bem como o endereço de acesso ao sistema Registrato.
