# Comunicado Nº 26.302

|  |
| --- |
|  |
|  |
| Em conformidade com o disposto na Circular nº 3.629, de 19 de fevereiro de 2013, comunico a seguinte errata na versão 4.03 do Catálogo de Serviços do SFN, publicado em 11/7/2014:    2. para a mensagem CTP1004, constante do volume 2, deve ser incluído o campo obrigatório “Tipo Mercado Título” na posição 27.    3. Os arquivos atualizados dos volumes 2 e 4 do Catálogo, do Dicionário de Domínios associado, do XSD do evento CTP1004, da planilha de alterações e do DRN que originou a alteração estão disponíveis no sítio internet da Comunicação Eletrônica de Dados do Banco Central do Brasil ([http://www.bcb.gov.br/?CEDSFNSERVICOS](http://www.bcb.gov.br/?CEDSFNSERVICOS "Ir para o sítio http://www.bcb.gov.br/?CEDSFNSERVICOS.")).    Eduardo Weller  Comitê Gestor da Comunicação Eletrônica de Dados no Âmbito do SFN |
