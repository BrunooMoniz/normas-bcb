# Comunicado Nº 25.142

Comunicamos que, em decorrência de necessidade de ajustes nos arquivos ACAM202, destinados à transferência de dados registrados no antigo Sistema Câmbio para as instituições autorizadas a operar no mercado de câmbio, disponibilizados no Sistema de Transferência de Arquivos (STA), em 5/8/2013, estamos procedendo a exclusão desses arquivos a partir dessa data.

2.           Os arquivos ACAM202 retificados estarão disponíveis no STA a partir de 10 de março de 2014.

3.           A nova versão do leiaute do arquivo ACAM202 também será divulgada na mesma data, no endereço eletrônico [http://www.bcb.gov.br/?ACAM202](http://www.bcb.gov.br/?ACAM202 "Ir para o sítio http://www.bcb.gov.br/?ACAM202.").

4.           As transações de consulta ao antigo Sistema Câmbio estão disponíveis até 30 de junho de 2014, quando serão desativadas.

5.           Eventuais dúvidas relacionadas ao assunto poderão ser encaminhadas para o endereço eletrônico [cambio@bcb.gov.br](mailto:cambio@bcb.gov.br "Ir para o sítio cambio@bcb.gov.br.").
